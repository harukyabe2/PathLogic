## 説明<br>

### ルール<br>
- 画面左上の黄色のキャラクターをいずれかの白色のマスにドラッグ＆ドロップで置く<br>
- 回転（青色のマス）や移動（黄色のマス）ができるブロックを操作し，ゴールまでの経路を構築する<br>
- 再生ボタンを押すとキャラクターが進むので，鍵を取ってゴール（色が変化しているマス）に辿り着けばクリア<br>
- 盤面外に落下したり，無限ループに陥った場合はリロードボタンを押す<br>
- 矢印マス → キャラクターの向きを変更する<br>
- 矢印回転マス → 矢印の向きを時計回りに90°回転する<br>
- テレポートマス → 同じ色のテレポートマスへ移動する
<br>

### 操作<br>
**タイトル画面**<br>
- **スタートボタン**：ステージ1からゲーム開始<br>
- **ステージセレクトボタン**：ステージを10個から選択してゲーム開始<br>
- **Esc**キー：ゲームをやめる

**ゲームプレイ**<br>
- **左クリック**：キャラクターを掴む・離す，回転・移動ブロックの操作<br>
- **右クリック**：カメラの視点回転<br>
- **再生ボタン**：シミュレーションを開始する<br>
- **リトライボタン**：シミュレーション開始前の状態に戻す<br>

**リザルト画面**<br>
- **ネクストステージボタン**：次のステージへ進む<br>
- **クイットゲームボタン**：タイトル画面に戻る<br>
<br>

## 作品のコンセプトと面白さ<br>
盤面を思考するフェーズとキャラクターを動かすフェーズを分離することで，頭の中でギミックの連鎖をシミュレーションするというアイデアが制作の原点です．<br>
回転や移動によって盤面を構築し，キャラクターを適切な場所に置く3Dパズルゲームです．キャラクターの初期方向や矢印マスによる方向転換，その他のギミックマスによる複雑なシミュレーションを試行錯誤することで成功させます．
<br>

## 本プロジェクトの制作目的<br>
本作品は，C++によるオブジェクト指向プログラミング力と，3Dプログラミング特有の数学，アルゴリズムの学習を目的に制作しました．<br>
単にゲームを完成させるだけでなく，将来的な機能追加に耐えうる拡張性の高い設計を意識して実装しています．
<br>

## 設計と機能説明

### 技術的なアピールポイント<br>
- **3D空間のアニメーション同期**<br>
キャラクターは移動や落下，テレポートに加え，ブロックに乗せた状態で回転・移動しても同期したアニメーションを実現しています．<br>
- **ロジックとレンダリングの分離**<br>
2Dの論理座標や状態を持つクラスと，それを3D空間に描画するクラスを分離しました．これにより，状態管理がシンプルになり，将来的な機能追加が容易な設計となっています．
<br>

### クラス説明
- **Gameクラス**<br>
ゲーム全体の心臓部であり，オブジェクトの初期化，状態（Editing, Simulating等）の管理，入力処理を統括する．
- **Board / BlockGroup / Tileクラス**<br>
2次元配列によってマス目の状態や回転・移動するマスの集合を管理する．アイテム取得判定やテレポートのロジックを提供する．
- **Playerクラス**<br>
キャラクターの論理的な座標（盤面上の位置・方向）や状態管理を行う．<br>
- **BoardRenderer / PlayerRendererクラス**<br>
BoardやPlayerのデータを受け取り，行列による回転・移動計算を用いて3Dモデルの描画・アニメーションを行う．<br>
- **CameraControllerクラス**<br>
3Dカメラの回転やキャラクター配置のレイの計算を行う．<br>
